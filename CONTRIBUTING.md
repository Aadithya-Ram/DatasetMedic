# Contributing

Thanks for helping make DatasetMedic more useful.

1. Read DEVELOPMENT.md and reproduce the behavior with a small synthetic dataset.
2. For bugs, describe the input format, expected result, actual result, version and operating system. Do not upload private data.
3. Keep analysis and transformation logic in the Python engine. Reuse it for previews and exports.
4. Add regression tests for meaningful behavior changes. Run Python tests, lint, the interface build and relevant browser scenarios.
5. Update documentation and screenshots when visible behavior changes.

New diagnostics should show evidence, explain their limitations, and avoid treating a heuristic as proof. Keep the app local and usable without accounts or paid APIs. Preserve reduced-motion and keyboard support.
